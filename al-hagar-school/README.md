# منصة مدرسة الحجر الثانوية المشتركة

> منصة عربية لإدارة العمليات المدرسية، بواجهة RTL وتجربة تجريبية محلية.

## نبذة
تجمع المنصة إدارة الصفوف والطلاب والمدرسين والحضور والدرجات والمالية والمكتبة والإعلانات في تطبيق ويب ثابت يعمل داخل المتصفح.

## المميزات المستهدفة
- أربعة أدوار: مدير المدرسة، مدرس، طالب، ولي أمر.
- لوحة تحكم وبطاقات إحصائية وإعلانات.
- إدارة الطلاب والمدرسين والصفوف.
- الحضور والغياب والدرجات والشهادات.
- الإدارة المالية والمكتبة والإشعارات.
- مساعد ذكي قابل للإعداد في مرحلة لاحقة.
- واجهة عربية RTL متجاوبة.

## التقنيات
HTML5، Tailwind CSS Play CDN، Vanilla JavaScript، Chart.js، LocalStorage.

## التشغيل محليًا
نزّل المستودع وافتح `index.html` في متصفح حديث. يلزم اتصال بالإنترنت لتحميل Tailwind والخطوط وChart.js. يمكن أيضًا نشر جذر المستودع على GitHub Pages.

## الحسابات التجريبية
| الدور | اسم المستخدم | كلمة المرور |
|---|---|---|
| مدير المدرسة | `admin` | `Admin@123` |
| مدرس | `teacher1` | `Teacher@123` |
| طالب | `student1` | `Student@123` |
| ولي أمر | `parent1` | `Parent@123` |

هذه الحسابات للتجربة فقط. لا تستخدم بيانات حقيقية أو كلمات المرور التجريبية في نسخة فعلية. بيانات التطبيق محفوظة محليًا في المتصفح وليست قاعدة بيانات مركزية، ويمكن أن تُفقد عند مسح بيانات الموقع. لا تعتبر LocalStorage مخزنًا سريًا.

## الخصوصية والنسخ الاحتياطي
لا تضع بيانات طلاب حقيقية في مستودع عام. النسخ الاحتياطي والاستعادة الكاملان ضمن مراحل لاحقة. كلمات المرور التجريبية معرفة في بيانات التهيئة على هيئة تجزئات مملحة، وليست نصوصًا صريحة.

## هيكل المشروع
راجع المجلدات `css/` و`js/` و`assets/` و`docs/`. الوثيقتان المرجعيتان `requirements.md` و`speckit.md` مرفقتان بجذر المشروع.

## المساهمة والترخيص
تُراجع التغييرات وفق `speckit.md`. لم يُحدد ترخيص قانوني بعد؛ يضاف بعد اعتماد مالك المشروع.
